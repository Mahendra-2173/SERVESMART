# Exported AI Conversations Directory (`ai-chats/`)

This directory is designated for storing all exported AI conversation transcripts used during the development of **SERVESMART**.

## Submission Requirements
The take-home assignment requires all AI interactions to be exported and committed to the repository for transparency.

## Contents
1. `chat-history.md`: Documented development log capturing architectural prompts, heuristic engine iterations, cross-validation design, and test suite requirements.
2. `[Your Exported Chat Files]`: Place any raw JSON, HTML, or Markdown exports from your Gemini / ChatGPT / Claude sessions directly into this folder before final submission.

## Acceptable Formats
- Raw JSON conversation exports (`conversations.json`)
- Markdown conversation logs (`chat_export_YYYY-MM-DD.md`)
- Single-file HTML exports (`chat_transcript.html`)
